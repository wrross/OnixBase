# OnixBase ☀️

Um site moderno e minimalista com uma saudação elegante de **"Bom dia!"**.

## 🚀 Tecnologias Utilizadas

- **HTML5** semântico
- **CSS3** avançado (Glassmorphism, gradientes radiais animados, tipografia Google Fonts *Outfit*)
- **JavaScript** puro (relógio dinâmico em tempo real)

## 💻 Visualização Local

Basta abrir o arquivo [`index.html`](index.html) diretamente em qualquer navegador moderno.

## 🌐 Publicação no GitHub Pages

Para ativar a exibição online gratuita pelo GitHub:
1. Vá até a aba **Settings** do repositório no GitHub.
2. Na barra lateral esquerda, clique em **Pages**.
3. Em **Branch**, selecione `main` e a pasta `/(root)`.
4. Clique em **Save**. O site estará disponível em:
   **https://wrross.github.io/OnixBase/**
